# Arnold's Fitness Management Portal

A full-featured fitness centre management system built in Python. Handles everything a real gym needs: customer registration, package purchases, class bookings, trainer management, an admin panel, and a live web-based statistics dashboard.

---

## Features

- **Customer portal** — register, log in, browse and book fitness classes
- **Package system** — purchase session packages; bookings deducted from balance
- **Infinite calendar** — class schedule auto-generates forward from trainer timetables, no manual setup needed
- **Admin panel** — add/remove trainers, plan one-off classes, cancel slots, look up any customer
- **Matplotlib charts** — revenue, bookings, and profit charts saved as PNG files
- **Statistics dashboard** — run `stats_html.py` after first use to generate an interactive HTML dashboard with filterable time ranges
- **Persistent JSON storage** — all data saved locally in a `data/` folder (no database required)
- **Historical seeding** — realistic 6-month backfill from November 2025 so the dashboard has data on first run

---

## How to Run

### 1. Install dependencies

```bash
pip install matplotlib
```

### 2. Run the main system

```bash
python fitnessproject2.py
```

This creates a `data/` folder with all JSON data files. Use the customer or admin login to explore the system.

### 3. Generate the stats dashboard (optional)

After running the main system at least once:

```bash
python stats_html.py
```

This reads from `data/` and generates `data/stats_report.html` — open it in any browser to view the interactive dashboard.

---

## Stats Dashboard

The dashboard is generated by `stats_html.py` and includes:

- **3 time range tabs** — Last 4 Weeks, Last 3 Months, Last 12 Months
- **KPI cards** — Total Bookings, Packages Sold, Package Revenue, Net Profit
- **Class Registrations by Type** — horizontal bar chart
- **Packages Purchased by Type** — donut chart
- **Top 5 Trainers by Bookings** — bar chart
- **Profit Breakdown** — revenue vs expenses bar chart

### Hosting on GitHub Pages

To publish the dashboard as a live URL:

1. Run `fitnessproject2.py` once (creates `data/`)
2. Run `stats_html.py` (creates `data/stats_dashboard.html`)
3. Copy `data/stats_dashboard.html` → `docs/index.html`
4. Push to GitHub and enable Pages from the `docs/` folder in repo settings
5. Live at: `https://0akku0.github.io/arnolds-fitness-portal/`
